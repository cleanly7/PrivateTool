# 私人工具箱

个人学习与日常使用的小工具集合：记账、冥想、专注时间、记录、喝水。

## 本地运行

```bash
npm install
npm run dev
```

打开 http://localhost:3000 使用。

常用脚本：

```bash
npm run typecheck   # tsc --noEmit
npm test            # node --test lib/*.test.ts
npm run build       # next build
npm run desktop     # build + 用 Electron 打开
npm run build:app   # 打包 .app（macOS）
```

## 工具说明

### 专注时间（原「番茄钟」）

给自己计时学习用：选「技术学习」或「日语」，只在真的在学的时候开着，
学到自然停下来，再确认实际时长和写一句复盘。结束的记录会直接汇总成复盘要填的两个数字：

- **计时方式**：正计时（`HH:MM:SS`），开始 / 暂停 / 继续 / 结束并保存 / 重置。暂停的时间不算进去，
  时长按墙上时钟算，刷新页面、切到别的标签页、甚至关掉窗口再打开，回来后显示的仍是真实的专注时长。
- **大标题**：开始前（或计时中）写一句「这段在做什么」，比如「黑马点评 第 12 集」（最多 120 字，留空也能开始）；
  旁边的「最近」按钮会列出最近 5 条用过的大标题（文本去重），第一项就是「继续上一次：<标题>」，点一下就能复用。
- **分心**：走神的时候点「分心了一下」，**点一下就记下**（不弹输入框），**计时一秒都不会停**；
  桌面版在窗口没聚焦时按 `⌘⇧D`（或 `Ctrl+Shift+D`）也能记，按完窗口会自己回到前面。
  记完会有一条 2.5 秒的「已记下第 N 次分心」提示，可以直接「撤销」；
  每条可以补一句原因（最多 100 字）或随手删掉；一段里最多 200 次（记满了会劝你先把注意力拉回来）。
- **45 分钟刻度**：计时器下面是一条 0–90 分钟的刻度条，45 / 90 各有一个刻度点（超过 90 分钟锁在 100%）；
  到 45 分钟只提醒一次（系统通知 + 界面上一行字），**不响铃、不暂停、不弹窗**。
- **结束并保存**：点「结束并保存」会弹窗让你确认实际学了多少分钟（1–1440，可以 ±5 或直接输入，
  毕竟最后一段时间可能没在学），再写一句「这次学到了什么」；弹窗里还会带上这段的大标题
  和记下的分心（可以逐条改原因、删掉，删掉的不会入库），以及科目与开始时间回显。
- **不会静默丢记录**：保存失败时窗口不会关掉、内容留在本地，可以「重试保存」；
  刷新页面或重开应用后弹窗会自己打开并提示「上次保存没有成功」，记录不会静默丢失。
- **忘停提醒**：超过 90 分钟会在结束弹窗里提示核对时长；超过 12 小时会提醒你是不是忘了停。
- **今日专注**：技术学习 / 日语各多少（主数字是 `0m` / `45m` / `2h5m` 这种分钟精度），
  点「复制到复盘」就能把 `技术学习 2 小时 30 分、日语 1 小时、合计 3 小时 30 分` 复制到剪贴板；
  今天记过分心的话会追加 `、分心 3 次`，面板上也会多出「分心 N 次」和每次的时间与原因（最多列 6 条，
  超出提示去记录页）。
- **本周专注**：本周合计、科目拆分、每天一根柱子、本周写下的学习备注（带大标题），
  以及合计区的一格「分心 N 次」。
- **总览**：页头的「总览」看全部历史累计、最专注的一天，以及按分类的年度热力图
  （周一起始、点某一列展开那一周）；切过去**不会打断正在跑的计时**，再点「返回计时」回来。
- **补录一段**：忘了开计时器也能事后补上——专注页页头的「补录一段」、记录页页头的「补录专注」开的是同一个弹窗：
  科目、开始时间（默认现在）、时长（1–1440 分钟，默认 60）、大标题、备注。这段算在**开始那天**
  （23:40 加 100 分钟这种跨零点也一样），所以补录的昨天不会加进今天的小时数。
  三条校验都就地提示：「开始时间不能晚于现在」「时长需为 1–1440 的整数」「这段的结束时间超过了现在，请检查时长」；
  保存失败弹窗不关，可以「重试保存」。

想改时长 / 科目 / 大标题 / 备注 / 分心，去「记录」页点那条记录右侧的铅笔：时长按分钟改（1–1440 的整数，
秒数会被舍去），分心可以逐条补原因、删掉记错的那条（直接点分心徽章也能打开这个弹窗）；
保存失败时弹窗不关、可以「重试保存」。冥想记录只能改备注与时长。
删除记录不再弹确认框：点垃圾桶后这一行立刻消失，底部出现一条 8 秒的「已删除记录 / 撤销」——
这 8 秒里记录**其实还没真的删**，所以点「撤销」一定能把原件放回来；8 秒过去才真正删除，
删不掉会明确告诉你失败了、并把这行放回列表。
喝水记录还没有编辑/删除入口（专注的「补录一段」见上面那条）。

记录的时长口径是 `sessions.actual_seconds`（真实有效秒数，扣掉暂停）；
老记录这一列是空的，统计时回退到 `planned_minutes * 60`。
归属日期按 `started_at` 算——23:40 开始、次日 00:20 结束的那段算在开始那天。

数据库里这类记录存 `kind = "focus"`（早期版本存的是 `"pomodoro"`，
启动时迁移会统一改名，`"pomodoro"` 这个名字留给以后的番茄钟模块）。
科目存在 `sessions.subject`（`tech` / `japanese`，空串表示未分类），
大标题存在 `sessions.title`；分心单独一张 **`time_distractions`** 通用表
（`target_kind = 'session'` + `target_id`，跟着记录一起删，一张记录可以挂多条；
`target_kind = 'schedule_block'` 是给以后的「日程」模块留的）。
科目记忆、计时草稿、保存失败待重试的记录都存在浏览器 `localStorage`
（键名 `focus-subject-memory` / `focus-timer-focus` / `focus-timer-focus-pending`）。
冥想仍然用倒计时计时器，共用 `components/FocusTimer.tsx`。

统计逻辑在 `lib/focus-stats.ts`（纯函数，单测见 `lib/focus-stats.test.ts`），
正计时/草稿/兜底保存的逻辑在 `lib/focus-timer.ts` 与 `lib/focus-session.ts`。

## 数据存储

数据保存在 `data/bookkeeping.db`（SQLite），已加入 `.gitignore`。备份时直接复制这个文件即可。

启动时会自动迁移老库：

- 缺 `subject` 列时 `ALTER TABLE` 补上，老记录留空、统计时算作「未分类」。
- `kind` 还是老字典（没有 `focus`）或缺少 `actual_seconds` / `title` 列时，
  会先 `VACUUM INTO` 备份成 `data/bookkeeping.backup-<时间戳>.db`，再重建 sessions 表把
  `pomodoro` 改名为 `focus`；备份失败只会打日志，不会拦住迁移。
- 早期版本的分心表 `focus_distractions` 如果存在，会把行搬进通用的 `time_distractions`
  （`target_kind` 填 `'session'`）后删掉旧表。迁移都是幂等的，重复启动没有副作用。

需要换数据目录时可以用环境变量 `PRIVATE_TOOLBOX_DATA_DIR` 指定。
